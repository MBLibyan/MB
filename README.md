# استوديو أعمالي | منصة استعراض الأعمال الصوتية والمرئية (MP3 & MP4)

تطبيق ويب متكامل مبني باستخدام **Next.js (App Router)** و **Tailwind CSS (Dark Mode)** و **Supabase (Database, Storage, Auth)** ومهيأ للنشر المباشر على **Vercel**.

---

## المميزات الرئيسية

### 1. الصفحة الرئيسية العامة للزوار (`/`)
- **عرض متناسق (Grid & List Views):** عرض جميع الأعمال الصوتية (`MP3`) والمرئية (`MP4`) المرفوعة مع شارات النوع والمدة وحجم الملف.
- **مشغل وسائط تفاعلي مدمج (Built-in Media Player):**
  - تشغيل سلس لملفات **MP3** و **MP4** (مع مسرح عرض مرئي مدمج قابل للتكبير وملء الشاشة للفيديو).
  - أزرار تحكم متكاملة: تشغيل/إيقاف مؤقت، إيقاف كامل، تقديم `+10s`، تأخير `-10s`، الانتقال للعمل التالي/السابق، التحكم بمستوى الصوت وكتمه، وتغيير سرعة التشغيل (`0.75x` إلى `2x`).
- **التصفية والبحث الفوري:** فلترة الأعمال حسب النوع (`الكل` / `صوتيات MP3` / `فيديو MP4`) مع بحث حي بالعنوان أو الوصف.

### 2. لوحة التحكم المحمية (`/admin`)
- **تسجيل دخول آمن (Supabase Auth):** حماية لوحة التحكم عبر البريد الإلكتروني وكلمة المرور الخاصة بالأدمن.
- **منطقة سحب وإفلات (Drag & Drop):** لرفع ملفات `MP3` و `MP4` مباشرة إلى **Supabase Storage** مع اكتشاف تلقائي لنوع الملف ومدته الزمنية.
- **شريط تقدم حي (Live Progress Bar):** يعرض نسبة الرفع المئوية الحقيقية (`0%` إلى `100%`) وحجم البيانات المرفوعة لحظياً أثناء الرفع إلى Supabase Storage.
- **إدارة الأعمال المرفوعة:** جدول/قائمة تفاعلية لتعديل تفاصيل أي عمل (العنوان، الوصف، النوع) أو **حذف العمل نهائياً** من كلٍ من جدول قاعدة البيانات ومن حاوية **Supabase Storage**.

## خطوات إعداد Supabase وربط المفاتيح في Vercel

### الخطوة 1: تهيئة قاعدة البيانات وحاوية التخزين في Supabase
1. افتح لوحة تحكم مشروعك في [Supabase](https://supabase.com/dashboard).
2. انتقل إلى قسم **SQL Editor** من القائمة الجانبية.
3. انسخ محتوى الملف [`supabase/schema.sql`](./supabase/schema.sql) وقم بتشغيله (**Run**).
   - سيقوم السكربت تلقائياً بإنشاء جدول `public.media_items` وتفعيل سياسات الحماية (RLS).
   - كما سيقوم بإنشاء حاوية التخزين العامة (Storage Bucket) باسم `media` وضبط صلاحيات القراءة للزوار والرفع/الحذف للأدمن.

### الخطوة 2: إنشاء حساب الأدمن في Supabase Auth
1. من لوحة تحكم Supabase انتقل إلى **Authentication → Users**.
2. اضغط على **Add User → Create New User** وأدخل بريدك الإلكتروني وكلمة المرور الخاصة بك لتسجيل الدخول عبر `/admin`.

### الخطوة 3: ربط مفاتيح Supabase في Vercel
1. في لوحة تحكم Supabase انتقل إلى **Project Settings → API** وانسخ:
   - `Project URL`
   - `anon / public key`
2. في لوحة تحكم **Vercel** الخاصة بمشروعك، انتقل إلى:
   **Settings → Environment Variables**
3. أضف المتغيرات التالية:

```env
NEXT_PUBLIC_SUPABASE_URL=https://your-project-id.supabase.co
NEXT_PUBLIC_SUPABASE_ANON_KEY=eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...
NEXT_PUBLIC_SUPABASE_BUCKET=media
```

4. اضغط **Save** ثم أعد نشر المشروع (**Redeploy**) لتفعيل المفاتيح.
